# 更新记录

陪伴猫小克每个版本的更新要点，新的在上面。自动更新发现新版时，截取新版本那一节的前几条告诉用户。

## 0.5.2

- 说明里提到右侧那块的地方统一叫「工作面板」，整体叫「<名字>AI工作台」（默认名改为「小黎」，见工作面板 0.9.2）；猫的功能、台词与命令都没变

## 0.5.1

- 名字改回「小克」：台词、提示、气泡、状态卡片与命令回复都叫小克（前几天改名叫「小黎」，现在改回来；「小黎」只指作者）
- 命令只留 `/xiaoke`，改名时加的 `/xiaoli` 去掉了
- 人设不再写死主人的名字，装在谁的电脑上都只叫「主人」；保活请求里的自称也改成小克
- 模型回复里带着「小克：」或旧的「小黎：」自称时照样去掉

## 0.5.0

- 可以从插件市场安装：`claude plugin marketplace add xiaoli1999/xiaoli-mods` 后装 `xiaoke@xiaoli-mods`
- 每天第一次开会话自动检查新版：插件市场安装的自动更新并重新加载插件，本地目录加载的提示 `git pull`
- 新增 README 与插件图标

## 0.4.3

- 缓存保活默认不设上限，一直保活到会话关闭；`/xiaoli keep max <小时>`、`keep max off` 设或取消上限（1 到 72 小时，跨会话记住）
- 安静模式不打扰：保活成功不弹提示，点「悄悄话」不调模型、直接回一句；保活失败、停下与额度提醒照常弹
- `/xiaoli ai off` 只关每轮结束的自动台词，「悄悄话」照样可用，说明文字写清楚

## 0.4.2

- 子代理开始时不再冲掉主对话这一轮的台词与统计
- 额度到 80% 的提醒同一个窗口只弹一次，记在 `$.store`，多个会话、热重载都不重复
- 会话跨过 0 点时「认识第 N 天」正确加一，多个会话不重复加
- 只有 `/xiaoli show` 能让藏起来的小黎出来；带子不足 4 行时点小黎会说明展不开
- 强提醒结束时保持你选的放松模式；悄悄话与每轮台词用同一套清洗

## 0.4.1 及更早

此前没有逐版记录，这里合并列出 0.4.2 修复之前已有的功能。
